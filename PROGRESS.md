## Standing Rules for This Project

1. **Always maintain this progress tracker.** Update "Current Phase" / "Status Summary" as work completes, and always write a dated entry in "Notes / Handoff" before stopping work for the session — even (especially) if the task was interrupted mid-way. No page invents its own one-off layout or component styling. Any exception requires an explicit, documented rationale, not a default under time pressure.
